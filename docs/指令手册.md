# 指令手册

## 玩家指令

权限 `fmkit.use`，默认所有人可用。`/fmkit` 可简写 `/fkt`。

| 指令 | 说明 |
|---|---|
| `/fmkit` | 打开选择页（私人/公共两个入口，各显示条数） |
| `/fmkit private` | 直达私人回收站 |
| `/fmkit public` | 直达公共回收站 |
| `/fmkit toggle` | 查看本人回收开关 |
| `/fmkit toggle on\|off` | 切换本人回收开关（同时管丢弃与死亡掉落） |
| `/fmkit help` | 用法帮助 |

## 管理指令

权限 `fmkit.admin`，默认 OP。`/fmkitadmin` 可简写 `/fkta`。

| 指令 | 说明 |
|---|---|
| `/fmkitadmin status` | 运营统计：双箱条数/容量、最旧条目、开关开/关人数 |
| `/fmkitadmin clearpublic` | 清空公共箱：先报条数，确认窗口（`admin.clearpublic-confirm-seconds`，默认 10 秒）内再执行一次确认。控制台可用 |
| `/fmkitadmin clear <玩家>` | 清空指定玩家私人箱。**离线可清**（按 UUID） |
| `/fmkitadmin bin <玩家>` | 打开他人私人箱 GUI，可浏览/逐条销毁 |
| `/fmkitadmin toggle <玩家> on\|off` | 代改他人回收开关。**离线可改** |
| `/fmkitadmin notify <玩家> off\|valuable\|all` | 代设他人到期提醒档。**离线可改** |
| `/fmkitadmin destroy <玩家> on\|off` | 代设他人到期去向（`on`=到期销毁）。**离线可改** |
| `/fmkitadmin reload` | 热重载配置 |
| `/fmkitadmin sweep on\|off` | 运行期开关扫地 |
| `/fmkitadmin sweep now` | 立即触发一次收集 |
| `/fmkitadmin interval <秒>` | 修改清理间隔并写入配置（下限 5 秒，立即重排任务） |
| `/fmkitadmin whitelist` | 查看双清单（贵重/忽略）内容 |
| `/fmkitadmin whitelist valuable\|ignore` | 查看单个清单 |
| `/fmkitadmin whitelist <清单> add\|remove <物品>` | 增删并写入配置 |
| `/fmkitadmin whitelist <清单> clear` | 清空清单 |
| `/fmkitadmin whitelist <清单> on\|off` | 启用/停用该清单 |
| `/fmkitadmin help` | 用法帮助 |

## GUI 操作

### 私人回收站（`/fmkit private`）

```
第 1 页：
  槽1 回收开关（绿=开/红=关）  槽2 到期提醒（三档循环）  槽4 说明书
  槽6 到期去向（转公共⇄销毁）  槽7 到期预览
  行1-4：条目卡片
  底行：上一页 | 页码 | 切换回收站 | 刷新 | 排序 | 全部取回 | 下一页
第 2 页起：54 格中 45 格全部放条目
```

| 操作 | 效果 |
|---|---|
| 左键条目 | 取回（背包装不下则拒绝，物品留箱） |
| 右键条目 | 立即转入公共回收站 |
| Shift+右键条目 | 销毁（两步确认：窗口内再点一次才执行） |
| 槽 52 全部取回 | 按存入顺序跨页装入背包，装满即停 |
| 槽 51 排序 | 三态循环：最先到期 → 最新 → 最旧 |

条目 lore 显示：丢弃时间、该条各自的转公共倒计时（绿 >半 → 黄 → 红）、原主人。

### 公共回收站（`/fmkit public`）

- 左键拿走，先到先得；无转公共/销毁（公共是终点）；
- 条目 lore：原主人（无主显示"无主"）、删除倒计时；
- 底行按钮与私人页相同（排序、全部取回、切换）。
