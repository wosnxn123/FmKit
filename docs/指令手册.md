# 指令手册

本仓库发布两个插件：FmKit（回收站）与 FmShop（商店）。

## FmKit 回收站

### 玩家指令

权限 `fmkit.use`，默认所有人可用。`/fmkit` 可简写 `/fkt`。

| 指令 | 说明 |
|---|---|
| `/fmkit` | 打开选择页（私人/公共两个入口，各显示条数） |
| `/fmkit private` | 直达私人回收站 |
| `/fmkit public` | 直达公共回收站 |
| `/fmkit toggle` | 查看本人回收开关 |
| `/fmkit toggle on\|off` | 切换本人回收开关（同时管丢弃与死亡掉落） |
| `/fmkit help` | 用法帮助 |

### 管理指令

权限 `fmkit.admin`，默认 OP。`/fmkitadmin` 可简写 `/fkta`。

| 指令 | 说明 |
|---|---|
| `/fmkitadmin status` | 运营统计：双箱条数/容量、最旧条目、开关开/关人数 |
| `/fmkitadmin clearpublic` | 清空公共箱：先报条数，确认窗口（`admin.clearpublic-confirm-seconds`，默认 10 秒）内再执行一次确认。控制台可用 |
| `/fmkitadmin clear <玩家>` | 清空指定玩家私人箱。**离线可清**（按 UUID） |
| `/fmkitadmin bin <玩家>` | 打开他人私人箱 GUI，可浏览/逐条销毁 |
| `/fmkitadmin toggle <玩家> on\|off` | 代改他人回收开关。**离线可改** |
| `/fmkitadmin notify <玩家> off\|valuable\|all` | 代设他人到期提醒档。**离线可改** |
| `/fmkitadmin destroy <玩家> on\|off` | 代设他人到期去向（`on`=到期销毁）。**离线可改** |
| `/fmkitadmin reload` | 热重载配置 |
| `/fmkitadmin sweep on\|off` | 运行期开关扫地 |
| `/fmkitadmin sweep now` | 立即触发一次收集 |
| `/fmkitadmin interval <秒>` | 修改清理间隔并写入配置（下限 5 秒，立即重排任务） |
| `/fmkitadmin whitelist` | 查看双清单（贵重/忽略）内容 |
| `/fmkitadmin whitelist valuable\|ignore` | 查看单个清单 |
| `/fmkitadmin whitelist <清单> add\|remove <物品>` | 增删并写入配置 |
| `/fmkitadmin whitelist <清单> clear` | 清空清单 |
| `/fmkitadmin whitelist <清单> on\|off` | 启用/停用该清单 |
| `/fmkitadmin help` | 用法帮助 |

### GUI 操作

#### 私人回收站（`/fmkit private`）

```
第 1 页：
  槽1 回收开关（绿=开/红=关）  槽2 到期提醒（三档循环）  槽4 说明书
  槽6 到期去向（转公共⇄销毁）  槽7 到期预览
  行1-4：条目卡片
  底行：上一页 | 页码 | 切换回收站 | 刷新 | 排序 | 全部取回 | 下一页
第 2 页起：54 格中 45 格全部放条目
```

| 操作 | 效果 |
|---|---|
| 左键条目 | 取回（背包装不下则拒绝，物品留箱） |
| 右键条目 | 立即转入公共回收站 |
| Shift+右键条目 | 销毁（两步确认：窗口内再点一次才执行） |
| 槽 52 全部取回 | 按存入顺序跨页装入背包，装满即停 |
| 槽 51 排序 | 三态循环：最先到期 → 最新 → 最旧 |

条目 lore 显示：丢弃时间、该条各自的转公共倒计时（绿 >半 → 黄 → 红）、原主人。

#### 公共回收站（`/fmkit public`）

- 左键拿走，先到先得；无转公共/销毁（公共是终点）；
- 条目 lore：原主人（无主显示"无主"）、删除倒计时；
- 底行按钮与私人页相同（排序、全部取回、切换）。

## FmShop 商店

### 玩家指令

权限 `fmshop.use`，默认所有人可用。`/fmshop` 可简写 `/fsh`。转账另需 `fmshop.pay`（默认所有人）；`fmshop.fee.exempt` 豁免手续费。

| 指令 | 说明 |
|---|---|
| `/fmshop` | 打开商店主界面（仅玩家） |
| `/fmshop buy <物品> [数量]` | 购买，数量默认 1 |
| `/fmshop sell <物品> [数量]` | 按物品名卖出，数量默认 1 |
| `/fmshop sell hand` | 卖出主手整组 |
| `/fmshop sell inv` | 一键卖出背包内全部可回收物（`all` 同义；创造模式拒绝） |
| `/fmshop price <物品>` | 查询买入/卖出价；动态商品附行情倍率与走势 |
| `/fmshop balance` | 查询本人余额 |
| `/fmshop balance <玩家>` | 查询他人余额（需 `fmshop.admin`） |
| `/fmshop pay <玩家> <金额>` | 转账：收 2% 手续费，单笔最低 1.0 |
| `/fmshop help` | 用法帮助 |

子指令缩写：`buy`=`b`，`sell`=`s`，`price`=`p`，`balance`=`bal`/`money`，`help`=`?`。卖出收 5% 手续费，买入不收。

### 管理指令

权限 `fmshop.admin`，默认 OP。`/fmshopadmin` 可简写 `/fsa`。每次余额变动都写入审计日志。

| 指令 | 说明 |
|---|---|
| `/fsa give <玩家> <金额>` | 加钱 |
| `/fsa take <玩家> <金额>` | 扣钱（余额不足则失败） |
| `/fsa set <玩家> <金额>` | 直接设定余额 |
| `/fsa price <物品> <买入> <卖出>` | 改价：写入 prices.yml 并热重载；`0` = 该方向不交易；拒绝卖出价 ≥ 买入价（防刷钱）。可为尚未上架的普通材料新建行（类目沿用旧行，否则 `misc`）。**附魔书生成行被拒绝**：`拒绝：该附魔书商品由 enchanted-books 配置块生成，请在 prices.yml 的 enchanted-books 区段中改价` |
| `/fsa market <物品>` | 查看行情：当前倍率、现价/基准价、累计买卖量 |
| `/fsa market <物品> reset` | 重置该商品行情 |
| `/fsa resetlimit <玩家>` | 清除该玩家今日买卖限额 |
| `/fsa resetlimit *` | 清除所有**在线**玩家的今日限额 |
| `/fsa resetunlock <玩家>` | 清除终身卖出计数（soldEver）：附魔书重新上锁、终身限售额度恢复。仅单人，故意不提供 `*` 形式 |
| `/fsa tax` | 查看公共税池余额与累计收取 |
| `/fsa tax take <玩家> <金额>` | 从税池拨款给玩家（余额不足则拒绝） |
| `/fsa audit [玩家] [条数]` | 查看交易审计记录：默认最近 10 条，条数范围 1–50 |
| `/fsa doctor` | 价格表体检（套利路径检测）：超 20 条转控制台输出 |
| `/fsa status` | 运行状态：商品/分类/未知 ID、账户数、手续费率、税池、已波动商品数、限额重置倒计时 |
| `/fsa reload` | 热重载配置与价格表 |
| `/fsa help` | 用法帮助 |

### 物品名解析

指令中的 `<物品>` 统一按 4 级顺序解析（大小写不敏感，空格视为下划线），任一级命中即返回：

1. **精确行 id** —— 素行如 `DIAMOND`；附魔书行 id 形如 `ENCHANTED_BOOK/SHARPNESS/5`，指令里写 `sharpness/5` 即可，如 `/fmshop price sharpness/5` 命中锋利 V 书；
2. **原版材料名** —— 命中该材料的素行；
3. **唯一前缀** —— 全表仅一行的 id 以此前缀开头时命中；
4. **唯一子串** —— 同上，按包含匹配，仍要求唯一。

任何一级匹配到多行都按未找到处理（报 `未找到该商品`），绝不随机选一行：裸写 `sharpness` 在 5 个等级间歧义，返回未知物品。

### 附魔书交易

- 附魔书行由 prices.yml 的 `enchanted-books:` 块生成：买入价 = 卖出价 × 6（素行为 × 2）。
- 每种书每名玩家**终身限卖 1 本**（永不重置）；卖出后才永久解锁购买。未解锁时购买报 `尚未解锁 —— 先向商店卖出 1 个，即可永久解锁购买`。
- 只有与行探针**精确匹配**的书可卖：多带一条附魔的书（如锋利 V + 耐久 III）报 `不回收`，绝不落回普通书行。

| 界面 | 布局 |
|---|---|
| 主界面 | 54 格：分类按钮占三排共 21 格（槽 10–16、19–25、28–34，当前用去 15 格）；槽 47 我的余额 / 49 一键回收 / 51 关闭 |
