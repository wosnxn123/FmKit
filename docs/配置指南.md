# 配置指南

FmKit 的配置在首次启动自动生成，支持热重载：

- `plugins/FmKit/config.yml`，`/fmkitadmin reload` 热重载

文案使用 MiniMessage 语法；`{占位符}` 为变量。本文只列结构性键位，完整文案清单直接看 `config.yml` 的 `messages:` 段。缺失的键自动回退到内置默认文案，删行不会报错。

## sweep —— 扫地/收集

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 扫地总开关 |
| `clean-interval` | `300` | 收集周期（秒）。运行期可用 `/fmkitadmin interval <秒>` 修改并写回配置（下限 5） |
| `countdown-start` | `60` | 进入倒计时广播的剩余秒数 |
| `countdown-times` | `[60,30,10,5,4,3,2,1]` | 在这些剩余秒数各广播一次。**固定时间点必播，不管地上有没有垃圾**（玩家依赖固定节奏） |
| `valuable-enabled` | `true` | 贵重清单总开关；关闭时贵重集合视为空 |
| `valuable-items` | 内置 152 种 | **贵重清单**：仅用于"只提醒贵重"档到期提醒的过滤，**不影响收集**。鞘翅/龙蛋/下界合金全套/钻石绿宝石/唱片/头颅/潜影盒/锻造模板/陶片/旗帜图案等 |
| `ignore.enabled` | `false` | 忽略清单总开关（默认关闭 = 所有物品都收集） |
| `ignore.items` | 与贵重同 152 种 | **忽略清单**：命中的地面物品**不收集、留在原地**自然消失。与贵重清单相互独立，可分别增删 |
| `excluded-worlds` | `[]` | 不参与扫地的世界名（不区分大小写） |
| `clean-experience-orbs` | `false` | 经验球始终直接删除（经验无法进箱） |
| `threshold-cleaning.enabled` | `false` | 掉落物数量超阈值时提前触发收集 |
| `threshold-cleaning.threshold` | `500` | 阈值 |
| `threshold-cleaning.check-interval` | `30` | 阈值检测周期（秒） |

**双清单要点**：贵重清单只管"提醒"，忽略清单只管"扫不扫"，两者默认内容相同但语义完全独立。运行期用 `/fmkitadmin whitelist [valuable|ignore] …` 增删并写回配置。

## collect —— 个人回收

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 私人箱收集总开关（死亡标记 + 扫地分流） |
| `default` | `true` | 每位玩家回收开关的初始值；玩家可用 `/fmkit toggle` 或 GUI 槽 1 修改 |
| `on-death` | `true` | 死亡掉落是否收进私人回收站（关闭时死亡掉落纯原版落地，被扫到进公共箱） |

## bins —— 回收站

时间单位均为**游戏日**（1 游戏日 = 20 分钟真实时间）；存储用真实时间戳，不受 `/time set`、停服影响。

| 键 | 默认 | 说明 |
|---|---|---|
| `private-ttl-days` | `3` | 私人箱保存期（3 游戏日 ≈ 1 小时真实时间） |
| `public-ttl-days` | `7` | 公共箱保存期（7 游戏日 ≈ 2.3 小时） |
| `private-max-entries` | `0` | 私人箱容量，`0`=不限；满则最旧条目**提前转公共** |
| `public-max-entries` | `512` | 公共箱容量，满则淘汰最旧；`0`=不限 |
| `expiry-scan-interval` | `60` | 到期流转/清理扫描周期（秒，下限 5） |
| `log.*` | 见说明 | 控制台箱日志（仅后台输出，不打扰玩家）：`overflow` 容量溢出（`off`\|`episode`\|`window`\|`each`，默认 `episode`=每次溢出期只记一行）、`public-expire` 公共箱到期清理（`off`\|`window`\|`each`，`window`=每 60 秒聚合成一行）、`private-expire` 私人箱到期流转（`off`\|`each`）、`sweep-deposit` 扫地入库汇总（`off`\|`each`）；后三个默认 `off` |
| `move-notify` | `VALUABLE` | **新玩家**到期提醒初始档：`OFF` \| `VALUABLE` \| `ALL`。存量玩家保留自选（旧 `true`/`false` 仍兼容，分别按 `ALL`/`OFF` 读） |
| `move-notify-mode` | `ACTIONBAR` | 提醒渠道：`ACTIONBAR` \| `CHAT` |
| `notify-max-shown` | `3` | 到期提醒最多按名列出几种物品，`0`=只报数量 |
| `expiry-warn-seconds` | `60` | 到期前 N 秒给在线主人发一次倒计时预警（每条每服务器生命周期仅一次），`0`=关 |
| `expiry-preview-minutes` | `10` | GUI 槽 7"到期预览"的时间窗（真实分钟） |
| `expiry-destroy` | `false` | **新玩家**到期去向初始值：`true`=到期销毁 / `false`=转公共 |
| `destroy-confirm-seconds` | `3` | Shift+右键销毁的两步确认窗口（秒） |

**到期流转规则**：私人条目到期 → 本人"到期去向"为销毁则销毁（按提醒档通知），否则移入公共箱（公共 TTL 重新起算，**存入时间保留原值**）。公共条目到期 → 删除。

## gui —— 界面

| 键 | 默认 | 说明 |
|---|---|---|
| `sounds` | `true` | 点击音效 |
| `auto-refresh-seconds` | `1` | GUI 打开期间自动重绘周期（秒），保持倒计时/预览新鲜；`0`=关 |
| `frame-material` | `GRAY_STAINED_GLASS_PANE` | 边框材质 |
| `dark-bar-material` | `BLACK_STAINED_GLASS_PANE` | 第 1 页顶行深色板 |
| `icons.*` | 见 config | 全部按钮/标记图标可换：`banner`（说明书）、`toggle-on/off`（回收开关）、`notify-valuable`、`expiry-to-public`、`expiry-destroy`、`preview`（到期预览）、`switch-to-public/private`、`prev/next-page`、`page-indicator`、`refresh`、`take-all`（全部取回）、`sort`（排序）、`hub-private/hub-public`（选择页入口） |

## admin —— 管理

| 键 | 默认 | 说明 |
|---|---|---|
| `clearpublic-confirm-seconds` | `10` | `/fmkitadmin clearpublic` 两步确认窗口（秒） |

## messages —— 文案

全部提示语（前缀、扫地广播、取回/销毁/流转、清单增删、GUI 标题与 lore、到期预览等约 69 条）均在 `messages:` 段，MiniMessage 语法，占位符 `{s}` `{n}` `{m}` `{item}` `{items}` `{player}` `{time}` `{t}` `{color}` `{dest}` `{state}` `{list}` `{name}`。

## 旧配置迁移

从旧版白名单扫地插件升级时，首次启动自动执行（迁移后旧键删除）：

| 旧键 | 迁移规则 |
|---|---|
| `sweep.whitelisted-items` + `whitelist-mode: EXEMPT`（或 `whitelist-enabled: true`） | 内容并入 `sweep.ignore.items`，`ignore.enabled=true` |
| `sweep.whitelisted-items` + `whitelist-mode: VALUABLE` | 内容并入 `sweep.valuable-items`，`valuable-enabled=true` |
| `sweep.valuable-items`（旧键，如有） | 并入贵重清单 |
| `bins.move-notify-exempt` | 并入贵重清单 |
| `bins.move-notify: true/false` | 按 `ALL`/`OFF` 兼容读取 |
