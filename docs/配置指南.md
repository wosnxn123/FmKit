# 配置指南

本仓库两个插件的配置均在首次启动自动生成，支持热重载：

- **FmKit**：`plugins/FmKit/config.yml`，`/fmkitadmin reload` 热重载
- **FmShop**：`plugins/FmShop/config.yml`（经济参数、GUI、文案）+ `plugins/FmShop/prices.yml`（价格表），`/fsa reload` 热重载

文案使用 MiniMessage 语法；`{占位符}` 为变量。本文只列结构性键位，完整文案清单直接看各自 `config.yml` 的 `messages:` 段。缺失的键自动回退到内置默认文案，删行不会报错。

# FmKit

## sweep —— 扫地/收集

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 扫地总开关 |
| `clean-interval` | `300` | 收集周期（秒）。运行期可用 `/fmkitadmin interval <秒>` 修改并写回配置（下限 5） |
| `countdown-start` | `60` | 进入倒计时广播的剩余秒数 |
| `countdown-times` | `[60,30,10,5,4,3,2,1]` | 在这些剩余秒数各广播一次。**固定时间点必播，不管地上有没有垃圾**（玩家依赖固定节奏） |
| `valuable-enabled` | `true` | 贵重清单总开关；关闭时贵重集合视为空 |
| `valuable-items` | 内置 152 种 | **贵重清单**：仅用于"只提醒贵重"档到期提醒的过滤，**不影响收集**。鞘翅/龙蛋/下界合金全套/钻石绿宝石/唱片/头颅/潜影盒/锻造模板/陶片/旗帜图案等 |
| `ignore.enabled` | `false` | 忽略清单总开关（默认关闭 = 所有物品都收集） |
| `ignore.items` | 与贵重同 152 种 | **忽略清单**：命中的地面物品**不收集、留在原地**自然消失。与贵重清单相互独立，可分别增删 |
| `excluded-worlds` | `[]` | 不参与扫地的世界名（不区分大小写） |
| `clean-experience-orbs` | `false` | 经验球始终直接删除（经验无法进箱） |
| `threshold-cleaning.enabled` | `false` | 掉落物数量超阈值时提前触发收集 |
| `threshold-cleaning.threshold` | `500` | 阈值 |
| `threshold-cleaning.check-interval` | `30` | 阈值检测周期（秒） |

**双清单要点**：贵重清单只管"提醒"，忽略清单只管"扫不扫"，两者默认内容相同但语义完全独立。运行期用 `/fmkitadmin whitelist [valuable|ignore] …` 增删并写回配置。

## collect —— 个人回收

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 私人箱收集总开关（死亡标记 + 扫地分流） |
| `default` | `true` | 每位玩家回收开关的初始值；玩家可用 `/fmkit toggle` 或 GUI 槽 1 修改 |
| `on-death` | `true` | 死亡掉落是否收进私人回收站（关闭时死亡掉落纯原版落地，被扫到进公共箱） |

## bins —— 回收站

时间单位均为**游戏日**（1 游戏日 = 20 分钟真实时间）；存储用真实时间戳，不受 `/time set`、停服影响。

| 键 | 默认 | 说明 |
|---|---|---|
| `private-ttl-days` | `3` | 私人箱保存期（3 游戏日 ≈ 1 小时真实时间） |
| `public-ttl-days` | `7` | 公共箱保存期（7 游戏日 ≈ 2.3 小时） |
| `private-max-entries` | `0` | 私人箱容量，`0`=不限；满则最旧条目**提前转公共** |
| `public-max-entries` | `512` | 公共箱容量，满则淘汰最旧；`0`=不限 |
| `expiry-scan-interval` | `60` | 到期流转/清理扫描周期（秒，下限 5） |
| `log.*` | 见说明 | 控制台箱日志（仅后台输出，不打扰玩家）：`overflow` 容量溢出（`off`\|`episode`\|`window`\|`each`，默认 `episode`=每次溢出期只记一行）、`public-expire` 公共箱到期清理（`off`\|`window`\|`each`，`window`=每 60 秒聚合成一行）、`private-expire` 私人箱到期流转（`off`\|`each`）、`sweep-deposit` 扫地入库汇总（`off`\|`each`）；后三个默认 `off` |
| `move-notify` | `VALUABLE` | **新玩家**到期提醒初始档：`OFF` \| `VALUABLE` \| `ALL`。存量玩家保留自选（旧 `true`/`false` 仍兼容，分别按 `ALL`/`OFF` 读） |
| `move-notify-mode` | `ACTIONBAR` | 提醒渠道：`ACTIONBAR` \| `CHAT` |
| `notify-max-shown` | `3` | 到期提醒最多按名列出几种物品，`0`=只报数量 |
| `expiry-warn-seconds` | `60` | 到期前 N 秒给在线主人发一次倒计时预警（每条每服务器生命周期仅一次），`0`=关 |
| `expiry-preview-minutes` | `10` | GUI 槽 7"到期预览"的时间窗（真实分钟） |
| `expiry-destroy` | `false` | **新玩家**到期去向初始值：`true`=到期销毁 / `false`=转公共 |
| `destroy-confirm-seconds` | `3` | Shift+右键销毁的两步确认窗口（秒） |

**到期流转规则**：私人条目到期 → 本人"到期去向"为销毁则销毁（按提醒档通知），否则移入公共箱（公共 TTL 重新起算，**存入时间保留原值**）。公共条目到期 → 删除。

## 旧配置迁移

从旧版白名单扫地插件升级时，首次启动自动执行（迁移后旧键删除）：

| 旧键 | 迁移规则 |
|---|---|
| `sweep.whitelisted-items` + `whitelist-mode: EXEMPT`（或 `whitelist-enabled: true`） | 内容并入 `sweep.ignore.items`，`ignore.enabled=true` |
| `sweep.whitelisted-items` + `whitelist-mode: VALUABLE` | 内容并入 `sweep.valuable-items`，`valuable-enabled=true` |
| `sweep.valuable-items`（旧键，如有） | 并入贵重清单 |
| `bins.move-notify-exempt` | 并入贵重清单 |
| `bins.move-notify: true/false` | 按 `ALL`/`OFF` 兼容读取 |

# FmShop

FmShop 有两份配置：`config.yml` 管经济参数、限额、GUI 与文案，`prices.yml` 管商品价格表。以下默认值即出厂文件内容。

## currency —— 货币

| 键 | 默认 | 说明 |
|---|---|---|
| `name` | `金币` | 货币显示名。金额内部按分存储（1 金币 = 100 分），无浮点误差 |
| `starting-balance` | `100.0` | 新玩家首次进服的初始余额（负数夹到 0） |

## fees —— 手续费

费率单位为基点（bp，100 bp = 1%），夹取范围 0–9000。持 `fmshop.fee.exempt` 权限的玩家免全部买/卖/转账手续费。

| 键 | 默认 | 说明 |
|---|---|---|
| `sell-bp` | `500` | 出售手续费：从卖出所得中扣除（500 = 5%） |
| `buy-bp` | `0` | 购买附加费：在买入价之上加收（0 = 不加收） |
| `pay-bp` | `200` | 转账手续费（200 = 2%） |
| `destination` | `void` | 手续费去向：`void` 直接销毁（推荐，抑制通胀）\| `tax-pool` 存入公共税池 |

## limits —— 限额

| 键 | 默认 | 说明 |
|---|---|---|
| `max-per-action` | `2304` | 单次买/卖操作最多处理的物品数量（2304 = 36 格 × 64），夹取 1–4096 |
| `min-pay` | `1.0` | `/fmshop pay` 的最小转账额（最低 0.01） |
| `reset-hour` | `4` | 每日限购/限售的重置时刻（本地时间，夹取 0–23） |

## gui —— 商店界面

| 键 | 默认 | 说明 |
|---|---|---|
| `auto-refresh-seconds` | `5` | 界面价格自动刷新间隔（秒），`0` = 关闭 |
| `sounds` | `true` | 交易音效 |
| `icons.*` | 见 config | 全部按钮图标可换：`filler`、`buy`、`sell`、`bag`、`balance`、`back`、`prev`、`next`、`close`、`confirm`、`cancel` |

## audit —— 审计

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 记录所有交易到 `plugins/FmShop/audit/YYYY-MM-DD.log` |
| `keep-days` | `14` | 日志保留天数，超期自动清理（下限 1） |
| `alert-above` | `10000.0` | 单笔金额达到该值时提醒在线管理员 |

## doctor —— 价格表体检

| 键 | 默认 | 说明 |
|---|---|---|
| `strict` | `false` | `true` = 价格表存在套利风险的商品直接拒绝加载；`false` = 仅在 `/fsa doctor` 中警告 |

## messages —— 商店文案

全部提示语（前缀、买卖/转账/限额/上锁、管理操作、GUI 标题等 42 条）均在 `messages:` 段，MiniMessage 语法。

## prices.yml —— 价格表

出厂表共 **1502 件商品 = 1374 手写行（`items:`）+ 128 行附魔书（`enchanted-books:` 块按曲线展开，不写进 `items:`）**，分 **15 个分类**（含 `enchants`）。

**差价不变量**：手写素行 `buy = 2 × sell`（个别注明的例外只会更保守）；附魔书行 `buy = 6 × sell`（`buy-multiplier: 6`）。改价后必须跑 `/fsa doctor`，它用服务器自己的配方表复核每条卖出价。

### items: —— 手写行

每行以材质名为键，可设：

| 键 | 默认 | 说明 |
|---|---|---|
| `buy` | 无 | 玩家买入价（每个）；`0` 或缺省 = 不出售 |
| `sell` | 无 | 玩家卖出价（每个）；`0` 或缺省 = 不回收。买卖价均为 0 的行被跳过 |
| `category` | `misc` | 所属分类 id |
| `daily-buy` / `daily-sell` | `0` | 每名玩家每日限购/限售（件），`0` = 不限；每天 `limits.reset-hour` 重置 |
| `unlock-by-sell` | `false` | 该商品对某玩家上锁，直到他向商店卖出过 1 个，之后永久解锁购买（要求 sell > 0） |
| `lifetime-sell` | `0` | 每名玩家终身最多卖出件数，永不重置；`0` = 不限 |
| `dynamic` | 继承 `dynamic-defaults` | 该行自己的行情参数 |

注意：给某行后加 `unlock-by-sell` 会让所有老玩家重新上锁（他们过去的卖出没有被记录）；管理员可用 `/fsa resetunlock <玩家>` 清除某人的终身计数。

### enchanted-books: —— 附魔书曲线展开

附魔书不逐条手写：26.2 原版 43 种附魔按各自等级展开为 **128 行**（42 种原版附魔最大等级之和 125，26.2 新增 `lunge` 3 级补足 128），价格全部由曲线推出——游戏更新加附魔时自动补齐，不留空洞。

```
sell = base-sell × 等级^level-exponent × rarity^rarity-exponent × 诅咒系数
buy  = sell × buy-multiplier
```

`rarity` 默认取原版 `Enchantment#getAnvilCost()`（1 / 2 / 4 / 8，下限夹到 1）——原版自己的"价值倍率"；诅咒附魔再乘 `curse-multiplier`。展开全表 sell 合计实测 31,042.94（由服务端附魔注册表推导，随版本变化，不是可写死的常量）。

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关；关闭则附魔书整类不上架 |
| `base-sell` | `24` | 曲线底价。必须 > 0，否则附魔书不加载 |
| `level-exponent` | `1.7` | 等级指数 |
| `rarity-exponent` | `1` | 稀有度指数 |
| `buy-multiplier` | `6` | 买价倍数。应 > 1，否则买价不高于卖价、可无限刷钱（doctor 会报） |
| `curse-multiplier` | `0.25` | 诅咒附魔的价格系数（诅咒也上架，免得留空洞看起来像 bug，但只值四分之一） |
| `category` | `enchants` | 展开行归入的分类 |
| `lifetime-sell` | `1` | 每名玩家每种书终身限售（永不重置） |
| `unlock-by-sell` | `true` | 卖出 1 本后该行永久解锁购买 |
| `daily-buy` / `daily-sell` | `0` | 每日限购/限售（件），`0` = 不限（出厂未设置） |
| `max-level` | `0` | 全局压级：>0 时所有附魔只展开到该等级；`0` = 按原版满级 |
| `exclude` | `[]` | 完全排除的附魔名单（接受 `MENDING` / `mending` / `minecraft:mending` 写法） |
| `dynamic` | 继承 `dynamic-defaults` | 附魔书行自己的行情参数 |

**`lifetime-sell: 1` + `unlock-by-sell: true` 必须保留**：治好的僵尸村民图书管理员可用 1 颗绿宝石换一本可交易附魔书（原版 tradeable 标签，含经验修补），不限售就是无上限刷钱。卖出才解锁购买则保住"自己附魔 / 自己找村民换"这段玩法——一次性套现，之后随便买。

**overrides —— 按附魔 / 按等级覆盖**：键为附魔名（`MENDING`，整种生效）或附魔名/等级（`SHARPNESS/5`，只改单个等级）；优先级：等级级 > 附魔级 > 曲线。可设 `rarity` / `sell` / `buy` / `max-level` / `daily-buy` / `daily-sell` / `lifetime-sell` / `unlock-by-sell`。出厂只改 rarity（改 rarity 而不是写死 sell，是为了保住该附魔的等级曲线——写死 sell 会把 I..V 全压成一个价）：

| 附魔 | rarity | 理由 |
|---|---|---|
| `MENDING` | `25` | 原版 anvil 只有 4，但它是唯一不可再生、且人人都要的附魔 |
| `THORNS` | `0.75` | anvil 8 是因为附魔台上少见，不是因为强；实战里没人抢 |
| `IMPALING` | `0.55` | 只对水生生物有效，5 级的曲线会把它顶到锋利 V 之上 |
| `BLAST_PROTECTION` | `1.2` | anvil 4 = 摔落保护的 4 倍，用途却窄得多 |
| `SMITE` | `0.5` | anvil 2 = 锋利的 2 倍，实战严格弱于锋利，不压会出现"更弱的附魔更贵"的倒挂 |
| `BANE_OF_ARTHROPODS` | `0.4` | 同上 |

**行身份与存档**：附魔书行 id 形如 `ENCHANTED_BOOK/SHARPNESS/5`（分隔符 `/`，附魔名大写；指令里可直接写 `sharpness/5`）。`market.yml`、审计日志、存档限额/终身计数全部以行 id 为键；素行的 id 就是材质名，与旧版 market.yml 的键格式一致，**旧存档无需迁移**。

**精确匹配**：只有与行探针完全一致的物品可卖——多带一条附魔的书（如锋利 V + 耐久 III）报"不回收"，绝不落回同材质素行。

**改价入口**：`/fsa price` 拒绝改附魔书生成行（提示"请在 prices.yml 的 enchanted-books 区段中改价"），只能改曲线参数或 overrides。
