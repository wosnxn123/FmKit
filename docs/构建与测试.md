# 构建与测试

## 构建

目标：Java 21（`--release 21`）。无第三方运行时依赖，仅 Paper/Folia API（`provided`）。

### 方式一：build.ps1（作者实际使用，免 Maven）

前提：本地 `.m2` 仓库里已有 paper-api 及其传递依赖的 jar（任何方式拉过一次即可，脚本把整个 `.m2` 的 jar 全部挂上 classpath）。

```powershell
cd FmKit
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

脚本流程：收集 `.m2` 全部非 sources/javadoc jar → `javac --release 21 -encoding UTF-8` 编译 `src/main/java` 到 `target/classes` → 复制 `config.yml`/`plugin.yml` → `jar uf` 增量打入 `target/FmKit-1.0.0.jar`。成功输出 `BUILD_OK`。

> 脚本内 `$root` / `$m2` 两个路径变量按需改。

### 方式二：Maven

```bash
cd FmKit
mvn package
```

`pom.xml` 声明 `io.papermc.paper:paper-api:26.2.build.115-stable`（scope `provided`，仓库 `repo.papermc.io`），产物同名 `target/FmKit-1.0.0.jar`。

### 部署

把 `FmKit-1.0.0.jar` 放进服务端 `plugins/` 重启；升级直接覆盖。

## 自动化测试

`bot/fmkit_test.js`：mineflayer 机器人进服真实操作 + RCON 驱动控制台，约 86 条断言，输出 `PASS`/`FAIL`/`FATAL`，退出码 = 失败数。

### 准备

1. 装好 FmKit 的 Folia/Paper 服务端，`server.properties`：

   ```properties
   online-mode=false
   enable-rcon=true
   rcon.port=25575
   rcon.password=fmtest123
   ```

   `fmtest123` 只是本地测试口令，可用 `RCON_PASS` 环境变量改。

2. 安装依赖（Node 18+）：

   ```bash
   cd bot && npm install
   ```

### 运行

```bash
node fmkit_test.js
```

环境变量（括号内默认值）：`PORT`（25567）、`RCON_PORT`（25575）、`MC_VERSION`（26.1，须与服务端协议一致）、`BOT_NAME`（FmTester）、`RCON_PASS`（fmtest123）。

### 套件设计

- **基线复位**：每轮开头 op 机器人、两步确认清空公共箱、提醒档重置 `valuable`、到期去向重置转公共，消除跨轮残留；
- **覆盖**：扫地分流与死亡标记（T0、I1-I7）、双清单增删持久化与 `sweep now`（I12 族）、私人箱翻页/取回/两步销毁（I27-I29、N6/N7）、到期提醒三档与图标颜色、管理代设（V0-V3、V7、A1-A5）、公共箱 TTL 过期（8d、V2/V2b）、全部取回与堆叠合并（I39-I40、V4-V6）、倒计时与 `interval` 持久化（I38）、`clearpublic` 两步确认（I8 族）、`bin`/`clear`/`status`/`toggle` 离线操作与无权限拒绝（I9、I34-I35）、分页（I36-I37）、`reload` 持久化（I40d）；
- **26.2 协议垫片**：`mc_shim.js` + `static_ids_26.2.json`（minecraft-data 尚未收录的版本映射），`captures_26.2.json` 为抓包样本；
- 断言依赖服务端为**离线模式**（机器人无正版验证）。
