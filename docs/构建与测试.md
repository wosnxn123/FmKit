# 构建与测试

## 构建

目标 Java 21（`--release 21`），无第三方运行时依赖，仅 Paper/Folia API（`io.papermc.paper:paper-api:26.2.build.115-stable`，scope `provided`，仓库 `repo.papermc.io`）。产物：

| 模块 | 版本 | 产物 |
|---|---|---|
| FmKit | 1.1.2 | `target/FmKit-1.1.2.jar` |

### 方式一：build.ps1（作者实际使用，免 Maven）

前提：本地 `.m2` 仓库里已有 paper-api 及其传递依赖的 jar（任何方式拉过一次即可，脚本把整个 `.m2` 的 jar 全部挂上 classpath）。默认取 `%USERPROFILE%\.m2\repository`，可用环境变量 `M2_REPO` 覆盖。

```powershell
cd FmKit
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

脚本流程：收集 `.m2` 全部非 sources/javadoc jar → `javac --release 21 -encoding UTF-8` 编译 `src/main/java` 到 `target/classes` → 复制资源（`config.yml`/`plugin.yml`）→ `jar cf` 打出上表产物。成功输出 `BUILD_OK`。

### 方式二：Maven

```bash
cd FmKit
mvn package
```

`pom.xml` 以 `finalName = ${project.name}-${project.version}` 产出上表同名 jar。

### CI（`.github/workflows/build.yml`）

push 到 `main`、任意 PR、或打 tag 时触发：ubuntu-latest + Temurin JDK 25，单个 job 在仓库根执行一次 `mvn -B -ntp package`，`target/*.jar` 上传为构件 `FmKit`。打 `refs/tags/v*` 的 tag 触发 GitHub Release 发布 FmKit。

### 部署

把对应 jar 放进服务端 `plugins/` 重启；升级直接覆盖。

## 自动化测试

mineflayer 端到端套件**不在本仓库**：它在作者本地与各插件仓库并列的 `bot/` 目录里，是 Fm 系列插件共用的一套 mineflayer + RCON 脚手架（同一目录下还有其它插件的用例），因此不随任何单个插件仓库发布。

套件行为：机器人真实进服操作 + RCON 驱动控制台，逐条输出 `PASS`/`FAIL`，结尾打印 `SUMMARY: 通过/总数`；存在失败时退出码 1，致命错误（`FATAL`）退出码 2。`HOST` 固定 `127.0.0.1`，只打本机服务端；断言依赖服务端为**离线模式**（机器人无正版验证）。

通用准备：

1. 服务端 `server.properties`：`online-mode=false`、`enable-rcon=true`，端口与口令和套件默认值一致（或用环境变量覆盖；`fmtest123` 只是本地测试口令）。
2. 安装依赖（需要 Node.js）：`cd bot && npm install`。
3. 26.2 协议垫片：`mc_shim.js` + `static_ids_26.2.json`（minecraft-data 尚未收录的版本映射），套件经 `require('./mc_shim')(版本)` 启用；`captures_26.2.json` 为抓包样本。

#### 套件设计

- **基线复位**：每轮开头 op 机器人、两步确认清空公共箱、提醒档重置 `valuable`、到期去向重置转公共，消除跨轮残留；
- **覆盖**：扫地分流与死亡标记（T0、I1-I7）、双清单增删持久化与 `sweep now`（I12 族）、私人箱翻页/取回/两步销毁（I27-I29、N6/N7）、到期提醒三档与图标颜色、管理代设（V0-V3、V7、A1-A5）、公共箱 TTL 过期（8d、V2/V2b）、全部取回与堆叠合并（I39-I40、V4-V6）、倒计时与 `interval` 持久化（I38）、`clearpublic` 两步确认（I8 族）、`bin`/`clear`/`status`/`toggle` 离线操作与无权限拒绝（I9、I34-I35）、分页（I36-I37）、`reload` 持久化（I40d）、指令别名 `/fkt`+`/fkta` 实服注册（N10/N11）。
